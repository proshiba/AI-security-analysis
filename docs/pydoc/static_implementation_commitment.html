static_implementation_commitment

実装

静的解析実装treeを有界列挙し、再開判断用commitmentへ固定する。

ImplementationSource

commitment対象となる通常単一link file。
ImplementationSource(relative_path: 'str', path: 'Path', size: 'int', device: 'int', inode: 'int', modified_ns: 'int', changed_ns: 'int') -> None

StaticImplementationError

静的解析実装treeの安全な固定に失敗したことを表す。

build_implementation_commitment

build_implementation_commitment( repository: 'Path', *, hash_file: 'Callable[[ImplementationSource], str]' ) -> 'tuple[dict[str, object], tuple[ImplementationSource, ...]]'
callerが安全に読んだhashからpath込みのcanonical commitmentを返す。

discover_implementation_sources

discover_implementation_sources(repository: 'Path') -> 'tuple[ImplementationSource, ...]'
対象suffixだけをreparse非追跡・件数／深さ上限付きで列挙する。

read_implementation_source

read_implementation_source(repository: 'Path', source: 'ImplementationSource') -> 'bytes'
列挙時identityと同じ通常単一link fileを1つのhandleから有界に読む。

verify_implementation_snapshot

verify_implementation_snapshot( repository: 'Path', sources: 'tuple[ImplementationSource, ...]', expected_sha256: 'dict[str, str]' ) -> 'None'
tree membership、identity、size、内容hashがsnapshotから不変か確認する。
