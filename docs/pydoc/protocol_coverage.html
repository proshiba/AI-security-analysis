公開済み根拠の整合性を監査する。通信互換性の実証や外部接続は行わない。

関数
       
audit_repository(repository: 'Path | str') -> 'dict[str, Any]'
固定設定と公開根拠を検証し、根拠本文を含まない監査結果を返す。
main(argv: 'list[str] | None' = None) -> 'int'
固定設定を読み取り、標準出力だけへ監査結果を表示する。
render_markdown(result: 'dict[str, Any]') -> 'str'
監査結果を日本語文書へ変換する。根拠の引用本文は出力しない。
