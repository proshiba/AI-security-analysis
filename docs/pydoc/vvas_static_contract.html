vvaS静的契約のPython API

保存済みvvaS逆アセンブルの同一性と受信境界を静的に監査する。 機械語byte欄はハッシュ照合だけに使用し、実行・CPUエミュレーション・通信・ 復号payload生成を行わない。命令の表示名やoperandの説明は根拠として信頼しない。 CLIだけが指定された通常の保存テキストを読み、結果を標準出力へ返す。

解析コード

公開関数

audit_receive_returns(values: 'list[int] | tuple[int, ...]') -> 'dict'
recv戻り値の数列だけを受動監査し、未完・終了・過剰を区別する。
 
実通信もpayload生成も行わない。過剰受信を見た監査器はfail-closedとし、
境界を越えて進み続ける実検体の不安全な動作を再現しない。
audit_saved_assembly(text: 'str') -> 'dict'
有界の保存asmを完全SHA-256へ束縛し、根拠offset付き監査結果を返す。
 
連続offset、命令byte欄、重要アンカー、全体サイズを検査する。
機械語を実行せず、再構成byteや検体由来文字列を結果へ含めない。
main(argv: 'list[str] | None' = None) -> 'int'
通常ファイルの保存asmを上限付きで読み、監査JSONを標準出力へ返す。

例外

StaticContractError: 入力が既知検体の静的契約または監査上限に適合しない。
