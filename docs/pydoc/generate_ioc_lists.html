generate_ioc_lists

実装

公開済み解析ごとに、決定的な IOC 専用 Markdown 一覧を生成する。

Indicator

根拠と確度を持つ、公開可能な単一の指標。
Indicator(type: 'str', value: 'str', role: 'str', confidence: 'str', source: 'str') -> None

analysis_directories

analysis_directories(results_root: 'Path', history: 'dict[str, dict]') -> 'list[Path]'
固定レイアウトの case、campaign、research、collection source を列挙する。

build_parser

build_parser() -> 'argparse.ArgumentParser'
決定的な IOC 一覧生成用 CLI を構築する。

canonical_case_ioc_rendering

canonical_case_ioc_rendering(directory: 'Path') -> 'tuple[str, int] | None'
publisher形式のiocs.jsonがあれば、それだけを信頼してMarkdownへ描画する。

clickfix_case_ioc_rendering

clickfix_case_ioc_rendering(directory: 'Path') -> 'tuple[str, int] | None'
ClickFix caseでは構造化IOCだけを信頼し、本文中の共有基盤を昇格しない。

collect_indicators

collect_indicators( directory: 'Path', repository: 'Path', history: 'dict[str, dict]' ) -> 'list[Indicator]'
単一解析について、保守的かつ公開可能な指標をすべて収集する。

confidence_from_text

confidence_from_text(text: 'str', default: 'str' = 'recorded') -> 'str'
明示された確度表現を、短い正規化ラベルへ変換する。

directory_hash_indicator

directory_hash_indicator(directory: 'Path') -> 'list[Indicator]'
SHA-256 形式のケースディレクトリ名を、提出検体ハッシュとして扱う。

generate

generate(repository: 'Path', *, write: 'bool' = False, check: 'bool' = False) -> 'dict'
IOC一覧の差分を計画し、明示時だけ生成または同期検証する。

history_indicators

history_indicators( directory: 'Path', repository: 'Path', history: 'dict[str, dict]' ) -> 'list[Indicator]'
解析履歴で確認済みの検体ハッシュと C2 項目を指標へ変換する。

indicator_type

indicator_type(value: 'str') -> 'str | None'
正規化済みの値を、公開可能な IOC 種別へ分類する。

indicators_from_config

indicators_from_config(path: 'Path') -> 'list[Indicator]'
設定 JSON 出力から、正規化済み抽出結果だけを読み取る。

indicators_from_indicators_json

indicators_from_indicators_json(path: 'Path') -> 'list[Indicator]'
新しいcase `indicators.json` の公開対象配列だけを読み取る。

indicators_from_ioc_json

indicators_from_ioc_json(path: 'Path') -> 'list[Indicator]'
ケース内の構造化 IOC 文書から、対応する指標を抽出する。

indicators_from_reviewed_findings

indicators_from_reviewed_findings( hashes: 'Iterable[str]', findings: 'Iterable[dict]' ) -> 'list[Indicator]'
横断報告用に、確認済みハッシュと構造化所見を正規化する。

indicators_from_text

indicators_from_text(text: 'str', role: 'str', confidence: 'str', source: 'str') -> 'list[Indicator]'
明示的に関連する文章片からハッシュとネットワーク指標を抽出する。

invalidated_ioc_rendering

invalidated_ioc_rendering(directory: 'Path') -> 'tuple[str, int] | None'
監査で無効化したIOCを旧資料から再抽出しない。

load_history

load_history(path: 'Path') -> 'dict[str, dict]'
正規化した結果ディレクトリ別に、解析履歴の項目を索引化する。

main

main(argv: 'list[str] | None' = None) -> 'int'
IOC一覧をdry-run、明示書込み、または同期検証する。

merge_indicators

merge_indicators(values: 'Iterable[Indicator]') -> 'list[Indicator]'
より強い根拠と確度を優先しながら、指標を重複排除する。

normalize_value

normalize_value(value: 'str') -> 'tuple[str, str] | None'
単一の候補を正規化し、種別と安全な値を返す。

read_relevant_markdown

read_relevant_markdown(path: 'Path') -> 'list[Indicator]'
明示的な IOC、C2、ネットワーク、設定の見出し配下だけから値を抽出する。

render_index

render_index(results_root: 'Path', reports: 'list[tuple[Path, int]]') -> 'str'
解析単位の IOC 一覧を横断する日本語索引を描画する。

render_ioc_list

render_ioc_list(values: 'list[Indicator]') -> 'str'
挙動説明を混在させず、日本語見出しの IOC 表を描画する。

reseal_tracked_ioc_list

reseal_tracked_ioc_list(directory: 'Path') -> 'None'
追跡済みIOC-LIST.mdのhashだけを更新し、reportを再封印する。

sanitize_url

sanitize_url(value: 'str') -> 'str | None'
IOC のパスを維持しながら、認証情報、クエリ、フラグメントを除去する。
