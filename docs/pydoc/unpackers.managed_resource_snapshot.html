unpackers.managed_resource_snapshot

実装

固定13table snapshotを既存resolverの内部stateへ接続する。

prepare_resource_snapshot

prepare_resource_snapshot( data, pe, *, max_resources=4096, max_resource_bytes=67108864, max_rows=20000, max_total_rows=80000 )
同じ13table予算を成立させ、固定resolverと作業量を返す専用factory。

resolver_from_resource_snapshot

resolver_from_resource_snapshot( pe, *, data, row_snapshot, max_rows=20000, max_total_rows=80000 )
原入力証明済みstateだけを固定resolverへ供給する。元constructor/classは変更しない。

revalidated_resource_scan

revalidated_resource_scan(data, scan)
同じbytes identityを要求し、毎消費時にsource/snapshot/descriptorを再照合する。

shared_metadata_state

shared_metadata_state( pe: 'Any', data: 'bytes', row_snapshot: 'Any', *, max_rows: 'int' = 20000, max_total_rows: 'int' = 80000 )
同じ入力と13table予約を再照合し、10tableへrow参照だけを供給する。
