winos_observation_session

実装 · 観測機能の利用と制約

検体別Winos通信を非実行で観測する、transport非依存の有界制御器。

受信本文は返さず、送信候補はCA01の固定C9／CBだけを生成する。
生成は送信ではなく、外部接続・登録・返信の許可を付与しない。

ObservationPolicy

検体の上限と区別して適用する防御側の資源上限。
ObservationPolicy(duration_ms: 'int' = 28800000, maximum_frame_bytes: 'int' = 65536, maximum_received_bytes: 'int' = 4194304, maximum_frames: 'int' = 4096, maximum_receive_calls: 'int' = 8192, partial_frame_timeout_ms: 'int' = 3000, maximum_prepared_frames: 'int' = 2881) -> None

PreparedControlFrame

固定protocol制御frameの候補。生成だけでは送信済みにならない。
PreparedControlFrame(kind: 'str', wire_bytes: 'bytes', elapsed_ms: 'int') -> None
metadata(self) -> 'dict[str, object]'
wire本文を含まない、生成済みという事実だけを返す。

WinosObservationSession

exact profileと合成session headerへ固定した単一接続の制御器。

``receive``は復号・分類だけを行う。``tick``の時刻は呼出側の単調時計から
与える。socket、DNS、実時計、再接続、端末情報収集、受信内容の実行は持たない。
CA01以外のtimer／返信を推測しない。外部runnerの既存profileは変更しない。
WinosObservationSession(profile_id: 'str', *, started_at_utc: 'str', policy: 'ObservationPolicy | None' = None, prepare_ca01_control_frames: 'bool' = False) -> 'None'
receive(self, data: 'bytes', elapsed_ms: 'int') -> 'tuple[dict[str, object], ...]'
分割・結合されたframeを有界に分類し、固定返信候補だけを別欄へ返す。
snapshot(self) -> 'dict[str, object]'
秘密本文を含まない現在状態と観測集計を返す。生成と送信を分離する。
tick(self, elapsed_ms: 'int') -> 'tuple[PreparedControlFrame, ...]'
期限・断片timeoutを検査し、CA01の固定heartbeat候補を最大1件返す。
 
名目10秒の静的待機を再現するが、遅延時に過去分をburst送信しない。
60秒超の受信沈黙時は送信候補を作らず停止する（検体より保守的）。

main() -> 'int'
