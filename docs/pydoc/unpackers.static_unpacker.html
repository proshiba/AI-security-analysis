unpackers.static_unpacker

実装

検体を実行せず、上限付きで静的展開とアーティファクト復元を行う。

外部静的toolの公開可能な有界実行結果。
StaticToolCompleted(returncode: 'int', stdout: 'str', stderr: 'str') -> None

StaticToolExecutionError

外部静的toolを有界に完了できなかった理由を保持する。
StaticToolExecutionError(reason: 'str') -> 'None'
