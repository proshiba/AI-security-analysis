triage_artifact_retrieval

実装

Triageの完全ハッシュ一致解析から次段・メモリ成果物を限定取得する。

api_json

api_json(path: 'str', api_key: 'str', *, opener: 'Any', timeout: 'float') -> 'Any'
許可済みTriage API pathから上限付きJSONを取得する。

build_parser

build_parser() -> 'argparse.ArgumentParser'
限定取得CLIの引数parserを構築する。

discover_candidates

discover_candidates( hashes: 'list[str]', api_key: 'str', *, opener: 'Any', timeout: 'float', include_memory: 'bool', root_sample_candidates: 'list[dict[str, Any]] | None' = None, report_memory_max_candidates: 'int' = 100, report_memory_max_bytes: 'int' = 67108864, report_memory_max_total_bytes: 'int' = 268435456 ) -> 'tuple[list[dict[str, Any]], list[dict[str, Any]]]'
完全hash一致の公開解析から取得候補と失敗分類を列挙する。

encrypted_zip_bytes

encrypted_zip_bytes(data: 'bytes', member_name: 'str', password: 'str') -> 'bytes'
平文をdiskへ書かず、AES-256 ZIPをmemory上で作る。

extract_artifact_candidates

extract_artifact_candidates( overview: 'dict[str, Any]', *, expected_sha256: 'str', sample_id: 'str', include_memory: 'bool' ) -> 'list[dict[str, Any]]'
overviewから、task境界を検証できる成果物API pathだけを作る。

extract_report_memory_candidates

extract_report_memory_candidates( report: 'dict[str, Any]', *, expected_sha256: 'str', sample_id: 'str', task_id: 'str', max_candidates: 'int' = 100, max_bytes: 'int' = 67108864, max_total_bytes: 'int' = 268435456 ) -> 'list[dict[str, Any]]'
task reportのregion dumpを、長さを検証したmemory取得候補へ変換する。

fetch_bounded

fetch_bounded( endpoint_path: 'str', api_key: 'str', *, opener: 'Any', timeout: 'float', max_bytes: 'int' ) -> 'tuple[bytes, dict[str, Any]]'
成果物を指定byte上限内で取得し、HTTP証跡を返す。

load_reviewed_candidates

load_reviewed_candidates(path: 'Path') -> 'list[dict[str, Any]]'
人手で確認した公開解析のmemory名を、安全なAPI候補へ変換する。

main

main(argv: 'list[str] | None' = None) -> 'int'
候補列挙と任意の暗号化取得を実行する。

normalize_sha256

normalize_sha256(value: 'Any') -> 'str'
SHA-256を小文字へ正規化し、不正値を拒否する。

persist_encrypted_archive

persist_encrypted_archive( archive_path: 'Path', archive_data: 'bytes', *, member_name: 'str', password: 'str', expected_size: 'int', expected_sha256: 'str' ) -> 'dict[str, Any]'
既存archiveを厳密検証し、新規archiveは同一directoryからatomic replaceする。

reported_behavioral_tasks

reported_behavioral_tasks( overview: 'dict[str, Any]', *, sample_id: 'str', max_tasks: 'int' = 2 ) -> 'list[str]'
overviewからreported状態のbehavioral taskを最大件数まで列挙する。

safe_basename

safe_basename(value: 'Any') -> 'str'
成果物名をbasenameへ限定し、危険な名前を拒否する。

safe_error_record

safe_error_record(error: 'Exception') -> 'dict[str, Any]'
秘密情報を含めず、再試行判断に必要な失敗分類だけを残す。

select_reported_candidates

select_reported_candidates( candidates: 'list[dict[str, Any]]', reference_hashes: 'list[str]' ) -> 'list[dict[str, Any]]'
完全一致解析で発見済みの候補をreport参照hashで一意に選ぶ。

utc_now

utc_now() -> 'str'
現在時刻をUTCのISO 8601形式で返す。

verify_encrypted_archive_bytes

verify_encrypted_archive_bytes( archive_data: 'bytes', *, member_name: 'str', password: 'str', expected_size: 'int', expected_sha256: 'str' ) -> 'str'
AES-256 ZIPの単一member、長さ、平文hashをmemory上で検証する。

verify_public_page

verify_public_page(sample_id: 'str', *, opener: 'Any', timeout: 'float') -> 'bool'
認証情報なしでTriage解析ページが公開されていることを確認する。

verify_reviewed_candidates

verify_reviewed_candidates( candidates: 'list[dict[str, Any]]', api_key: 'str', *, opener: 'Any', timeout: 'float' ) -> 'None'
review済み候補も、完全hash一致かつ公開解析であることを再検証する。
