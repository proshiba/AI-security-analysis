unpackers.go_decoder_shape

実装

Go decoderの全本文・branch・runtime callをレビュー済みshapeへ照合する。

実行、CPU emulation、file書込み、networkを行わない。
関数名乱数・検体SHA・復号keyをshapeの選択には使用しない。

ShapeError

未知または壊れたshapeをfail-closedで拒否する。

function_shape

function_shape( instructions: 'list[dict]', function: 'dict', functions: 'list[dict]', read_va=None, *, deadline: 'float | None' = None, clock: 'Callable[[], float]' = <built-in function monotonic> ) -> 'dict'
連続全命令を照合可能な形式へ正規化し、強い全本文digestを返す。

require_reviewed_shape

require_reviewed_shape(value: 'dict', profiles: 'list[dict]') -> 'dict'
全本文とreview済みshapeが一致する場合だけprofileを返す。
