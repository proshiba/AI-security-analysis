unpackers.go_embedded_pe

実装

Go関数表と明示的なbyte復号処理から埋込みPEを有界静的回収する。

Go、復元PE、CPU命令を実行せず、ファイル書込みや外部通信もしない。
包装形式の復元を、終端到達・ファミリー・C2の確認とは扱わない。

GoRecoveryError

不正構造や上限超過の理由だけを保持する安全な例外。

recover_go_embedded_pe

recover_go_embedded_pe( data: 'bytes', *, clock: 'Callable[[], float]' = <built-in function monotonic> ) -> 'tuple[dict, list[tuple[str, bytes]]]'
Go1.20以降の関数表と確認済み復号数学が一致する場合だけPEを返す。
