extractors.purehvnc.extractor

実装

検体を実行せずnative PureHVNCとmanaged PureRATの設定を抽出する。

ConfigCandidateBoundaryError

設定候補の上限・完全性境界を満たせず走査が不完全になったことを表す。

ParsedProtobufFields

値と同じ順序のprotobuf wire typeを保持するfield mapping。
ParsedProtobufFields(values: 'Mapping[int, Sequence[Any]]', *, wire_types: 'Mapping[int, Sequence[int]]') -> 'None'

ProtobufLimitError

共有protobuf parserが安全上限で未完了になったことを表す。

certificate_metadata

certificate_metadata(value: 'str') -> 'dict[str, Any]'
秘密鍵を公開せずPKCS#12証明書の公開metadataだけを返す。

decode_config_blob

decode_config_blob(strings: 'list[str]', raw_blobs: 'list[bytes] | None' = None) -> 'tuple[bytes, dict[int, list[Any]]]'
Base64／raw GZip／protobuf候補から一意なPureRAT設定を返す。

extract

extract(data: 'bytes', name: 'str' = 'sample') -> 'dict'
直接またはCHRD経由の設定を復元し、managed成功だけを標準契約へ反映する。

extract_chrd_carrier

extract_chrd_carrier(data: 'bytes') -> 'tuple[dict[str, Any], dict[str, Any]]'
CHRD／Donut carrierを静的復元し、managed終端のPureRAT設定を抽出する。

extract_direct_config

extract_direct_config(data: 'bytes') -> 'tuple[dict[str, Any], str]'
回収済み終端payloadからmanaged設定またはnative候補を抽出する。

extract_managed_config

extract_managed_config(data: 'bytes') -> 'dict[str, Any]'
managed PureRATの厳密protobuf設定と公開証明書fingerprintを抽出する。

extract_native_config

extract_native_config(data: 'bytes') -> 'dict[str, Any]'
native 10FX PureHVNCの確認済みmarkerとendpoint候補を保守的に抽出する。

iter_dotnet_user_strings

iter_dotnet_user_strings(data: 'bytes') -> 'Iterator[str]'
有効な#US heapがある.NET PEだけから範囲内の文字列を返す。

native_endpoint_candidates

native_endpoint_candidates(strings: 'list[str]', adjacency: 'int' = 2) -> 'list[str]'
隣接native IP／portを相関し、無関係なport風文字列を除外する。

parse_protobuf

parse_protobuf(data: 'bytes') -> 'ParsedProtobufFields'
確認済みPureRAT設定で使うprotobuf wire typeを境界付きで解析する。

read_varint

read_varint(data: 'bytes', offset: 'int') -> 'tuple[int, int]'
protobuf varintを1個読み、値と次のoffsetを返す。
