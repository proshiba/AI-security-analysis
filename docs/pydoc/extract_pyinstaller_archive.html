extract_pyinstaller_archive

実装

PyInstaller CArchiveを実行せず、安全な範囲で一覧化・静的展開する。

MemoryCArchiveEntry

全TOC検証後に保持する、展開前entryの不変metadata。
MemoryCArchiveEntry(index: 'int', name: 'str', normalized_path: 'str | None', offset: 'int', compressed_size: 'int', uncompressed_size: 'int', compressed: 'bool', typecode: 'str', is_option: 'bool', name_source: 'str' = 'archive_name', name_field_sha256: 'str | None' = None, name_field_size: 'int | None' = None) -> None

MemoryCArchiveError

メモリ上のPyInstaller CArchiveが不正または上限超過であることを示す。

MemoryCArchiveReader

境界を検証しながらbytes上のPyInstaller CArchiveを読む。

先頭NULの匿名script recordだけはTOC順序に束縛した合成名で保持し、元の
name領域はsizeとSHA-256で記録する。通常のpath検証を緩和せず、NUL後の
不透明bytesをpathやコードとして解釈しない。
MemoryCArchiveReader(data: 'bytes', *, max_toc_size: 'int' = 16777216, max_entries: 'int' = 16384) -> 'None'
extract( self, name: 'str', *, max_size: 'int' = 67108864, max_compressed_size: 'int | None' = None ) -> 'bytes'
指定entryだけを上限付きでメモリへ展開する。

RecoveredCArchiveEntry

優先選択してメモリ内だけで復元したentry。``payload``は公開reportへ含めない。
RecoveredCArchiveEntry(name: 'str', normalized_path: 'str', typecode: 'str', category: 'str', payload_format: 'str', priority: 'int', compressed: 'bool', compressed_size: 'int', uncompressed_size: 'int', sha256: 'str', payload: 'bytes', name_source: 'str' = 'archive_name', name_field_sha256: 'str | None' = None, name_field_size: 'int | None' = None) -> None
public_metadata(self) -> 'dict[str, object]'
payloadを除いた、公開可能な小さいmetadataを返す。

SelectiveCArchiveAnalysis

公開用集約reportと、非公開の復元bytesを分離した解析結果。
SelectiveCArchiveAnalysis(report: 'dict[str, object]', recovered_entries: 'tuple[RecoveredCArchiveEntry, ...]') -> None

analyze

analyze( sample: 'Path', expected_sha256: 'str', output_dir: 'Path | None' = None, exact_names: 'set[str] | None' = None, prefixes: 'tuple[str, ...]' = (), max_files: 'int' = 128, max_total_size: 'int' = 268435456, max_compressed_total_size: 'int' = 268435456, max_entry_size: 'int' = 67108864, max_toc_size: 'int' = 16777216, max_toc_entries: 'int' = 16384 ) -> 'dict[str, object]'
SHA-256一致を確認し、CArchiveを実行せず選択的に一覧化・展開する。

analyze_carchive_bytes

analyze_carchive_bytes( data: 'bytes', *, preferred_names: 'Iterable[str]' = (), max_retained_entries: 'int' = 128, max_entry_compressed_size: 'int' = 67108864, max_entry_uncompressed_size: 'int' = 67108864, max_total_compressed_size: 'int' = 134217728, max_total_uncompressed_size: 'int' = 134217728, max_validation_entry_compressed_size: 'int' = 67108864, max_validation_entry_uncompressed_size: 'int' = 67108864, max_validation_total_compressed_size: 'int' = 268435456, max_validation_total_uncompressed_size: 'int' = 268435456, max_validation_seconds: 'float' = 120.0, max_toc_size: 'int' = 16777216, max_toc_entries: 'int' = 16384 ) -> 'SelectiveCArchiveAnalysis'
PyInstaller CArchiveを実行・保存せず、優先entryだけをbytesへ復元する。
 
TOC全体の境界、path衝突、payload range重畳は選択前に検証する。全entryが
内容検証budget内なら1件ずつ展開してEOF・実サイズ・hashを検証し、非候補bytes
は即時破棄する。script、module、PYZ、PE名候補、入れ子archiveだけを優先順で
128件以下保持する。budget超過時は選択entryだけを検証し、部分状態を明示する。
PyInstallerという包装形式だけからmalware familyや悪性意図は推定しない。
