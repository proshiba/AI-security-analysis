winos_host_emulator

実装 · 観測機能の利用と制約

ValleyRAT/Winos control C2向けの有界・非実行host観測adapter。

review済みcontrol endpointへ固定C9 heartbeatを1回だけ送信し、返された
完全な1 frameをサイズ、SHA-256、command roleだけへ正規化する。C9の既知flag
``01``はregistration要求として区別するが、registration、未知commandへの応答、
stage取得、実端末情報の収集・送信は行わない。
